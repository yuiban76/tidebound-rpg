# 海賊王 AI RPG：風車村起航

以《海賊王》東海為舞台的 1～4 人繁中純文字 AI RPG 同人作品。故事從魯夫剛乘小船離開黎明島風車村的那天早上開始。玩家角色原本就是朋友，但還沒有海賊團、船長或共同的船。玩家用自然語言行動，房主電腦上的規則引擎負責決定擲骰、時間、金錢、物品與任務結果；AI 只負責理解意圖、旁白和 NPC 台詞。

## 在房主電腦啟動

需安裝 Node.js 24.14 或更新的 24.x 版本。Windows PowerShell 若限制 `npm.ps1`，請改用下列 `npm.cmd`；macOS／Linux 使用 `npm`。

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

1. 先啟動能回傳文字的模型服務，再開啟 [房主介面](http://127.0.0.1:4173)。
2. 首頁的「AI 連線設定」要填 OpenAI 相容 API 的 Base URL、Model ID，以及需要時的 API Key。Base URL 通常以 `/v1` 結尾，例如 Ollama 的 `http://127.0.0.1:11434/v1`、LM Studio 的 `http://127.0.0.1:1234/v1`。
3. 按「**測試連線並生成回覆**」。服務會實際請模型生成一句短回覆，回覆必須是非空白文字才算通過；只是連得上 `/models` 不算。**在測試通過之前，「建立房間」和「開啟存檔」都會停用。** 失敗時會顯示原因分類：連線被拒、找不到端點、認證失敗、模型不存在、逾時、空白輸出、格式不符或推論中斷。
4. 通過後建立房間。每位玩家填寫角色卡、確認原本就是朋友的共同背景並準備。目前在房內的 1～4 人都準備好後，房主即可按「開始遊戲」；按下時服務會再實際生成一次回覆確認 AI 仍可用。
5. 遊戲中 API 失聯時，需要 AI 的正式行動與世界推進都會暫停，已提交的結果和待處理行動會保留。房主重新測試通過後，待處理行動會接著執行。服務閒置五分鐘以上、期間沒有任何成功的生成時，會自動重測一次。
6. API Key 只保存在房主服務的執行記憶體中，服務重啟後需重新輸入。Key 不會送到前端、遠端玩家、WebRTC 封包或事件紀錄。

修改前端時，可在另一個終端執行 `npm.cmd run dev`。Vite 開發伺服器會把本機指令轉送到 `127.0.0.1:4173`。

### 故事線：從東海到頂上戰爭

有船之後可以投票選航線出海。全程共 23 座島：

**東海**（自由航行）
- 黎明島 → 謝爾茲鎮 → 橘子鎮 → 西羅布村 → 海上餐廳巴拉蒂 → 可可亞西村 → 羅格鎮
- 另有原創小島潮燈島與霧灣島。

**偉大航路**（要帶記錄指針，依航線順序前進）
- 羅格鎮 →（翻越顛倒山）→ 雙子岬 → 威士忌山峰 → 小花園 → 磁鼓島 → 阿拉巴斯坦 → 加亞島
- 加亞島之後：
  - 抓到南方鳥的話，可以乘衝天海流上空島，再到七水之都。
  - 也可以直接走遠路到七水之都。
- 七水之都 ↔ 司法島
- 七水之都 → 恐怖三桅帆船 → 夏波帝諸島
- 夏波帝諸島 ↔ 馬林福特
- 夏波帝諸島 ↔ 亞馬遜百合（穿越無風帶）
- 亞馬遜百合 → 推進城：要先取得女帝的協助。
- 推進城 → 馬林福特

**島上內容**
- 每座島有 3 個地點、當地的原作人物，以及 1 個委託。
- 例子：替莉卡把飯糰送給索隆、揭穿阿拉巴斯坦的舞粉真相、在正義之門前救出羅賓、推進城大脫獄、頂上戰爭。
- 偉大航路的單趟航行要花一到四個遊戲日。

**你們不是魯夫**
- 玩家角色是魯夫的同時代人，不必照著主線跑。想當海賊、賞金獵人、商人或醫生都可以，要去哪座島、接不接委託都由你們決定。
- 魯夫也活在這個世界裡，按原作航路自己移動，例如第 2 天在謝爾茲鎮、第 3 天在橘子鎮、第 25 天在阿拉巴斯坦。他到某座島時，如果你們剛好也在那座島上，世界公告會出現【目擊】，你們就能找他聊天。
- 他說的話會隨旅程改變，例如身邊多了哪些夥伴、正要去哪裡。
- 如果你們先改變了局勢，他的行程也會跟著改變。例如先救出艾斯，他就不會去闖推進城。

**時間線**
- 原作事件排在遊戲日曆上，第 1 天早上 8 點是魯夫離開風車村的那一刻。例子：
  - 第 2 天：謝爾茲鎮的蒙卡上校倒下。
  - 第 25 天：阿拉巴斯坦的雨。
  - 第 48 天：司法島。
  - 第 52 天：艾斯被捕。
  - 第 72 天：頂上戰爭。
- 事件到了時間就會發生：NPC 會離開或移動，說的話也會改變。
- 消息會出現在世界公告：隊伍在那座島時標示為【目擊】，不在時標示為【報紙】。
- 原作後續劇情不是腳本。只要在事件發生前完成對應的委託，結果就會改寫。例如：
  - 先揭穿舞粉真相，阿拉巴斯坦的內戰就不會爆發。
  - 在第 70 天艾斯被押走前，先從推進城救出他，頂上戰爭就不會照原作發生。
- 已經被時間線了結的委託會標示為「已落幕」。

**強度門檻**
- 關鍵委託有建議等級和較高的判定難度，例如阿拉巴斯坦 3 級、推進城 7 級、頂上戰爭 9 級；單靠幸運的 D20 無法跨越實力差距。
- 偉大航路的委託和首次登島會給更多 XP，所以只要一路冒險，就能在故事進程中成長到足夠的等級。

在任何一座島上說「去港口」「去碼頭」「去大街」「去處刑台」，都會解讀為目前所在島嶼的那個地點。

### 常用說法

- 「我能去哪裡？」「附近能做什麼？」列出附近地點和提示，不需要等 AI。
- 「去派對酒吧，找瑪琪諾聊天」會先移動再交談；交談中可以直接追問，例如「小艇上是誰？」。
- 「接受潮汐簿委託」「交還潮汐簿」「成立海賊團」「買船」「準備出航」「出海」「出海前往阿拉巴斯坦」「買記錄指針」。
- 「等待 8 小時」「等 3 天」：原地等待，最多 10 天；每滿 8 小時會像睡眠一樣恢復。多人時全隊都要在線並在同一地點才能等待，不會有人單獨把世界時間快轉。
- **戰鬥**：「攻擊村長」「強力攻擊 海賊船員甲」「連續攻擊」「用「風車斬」攻擊 岬恩」「防守」「撤退」「和蘇芮交涉」「使用繃帶給隊友名字」「裝填」。戰鬥面板也有按鈕可以直接帶入指令。
- **轉交與換武器**：「給隊友名字 300 貝里」「把繃帶交給隊友名字」「改用普通長槍」「收起武器」。轉交對象必須是同一地點的隊友。潮汐簿交給隊友後，改由接手的人交付委託。
- 世界公告上方的地圖會顯示步行地點和隊友位置，點地點會把移動指令帶進行動欄。

## 規則重點

- **人數與決議**：N 是已入隊並持有角色的真人玩家數（1～4）。一般決議門檻為 `floor(N/2)+1`；成立海賊團、出售主船等重大決議需要 N/N 全員同意；跨島出航需要全員到船邊並準備。斷線的玩家仍算在 N 裡。
- **開局後加入**：故事開始後，人數未滿 4 人時仍可用邀請連結加入。新玩家先完成角色卡、確認背景並準備，隨後在隊伍主船停泊的港口（還沒有船時則是風車村港口）與大家會合，世界公告會寫出這件事。加入前不算進 N，也不能行動或投票；入隊後，進行中的重大決議要連新人一起同意。
- **D20 與戰鬥**：固定 DEF＝12＋AGI＋閃避。自然 20 有效命中時加擲一次武器骰。HP 歸零是倒下而不是死亡。戰鬥採同步回合：同地的隊友都會參戰，全員鎖定行動後同時結算，離線的參戰者不會被代為操作。
- **對手**：
  - 任何 NPC 都能攻擊。強度依原作分成平民、雜兵、戰士、軍官、精英、七武海／大將級、傳說級，等級差距大時幾乎打不中。
  - 自然系（斯摩格、克洛克達爾、艾涅爾、艾斯）的身體會讓普通攻擊穿過；要等之後加入霸氣才能打中。
  - 被打倒的 NPC 會昏倒 8 小時，期間無法交談；他們會記得是誰打倒了自己。
  - 打倒原作頭目會立刻改變世界，原作事件也會改寫成「早已被一群旅人打倒」。例如惡龍、克洛、貝拉米、摩利亞、路基。
- **招式與體力**：
  - 普通攻擊 0 STA；強力攻擊 2 STA（傷害＋2）；基礎特殊招式 3 STA（命中＋1、傷害＋3）；進階招式 5 STA（命中＋2、傷害＋5）；連續攻擊 7 STA（連打兩下，命中各－2）。
  - 可以在狀態欄自創最多 6 個招式，只決定名稱與等級，華麗的名字不會讓它更強。
- **戰鬥中的行動**：防守（DEF＋2）、撤退（退到相鄰地點）、交涉（勸對手收手，精英以上不為所動）、使用繃帶（治療自己或同地隊友）、裝填火槍。
- **戰利品、賞金與聲望**：
  - 打倒對手可得貝里和 XP；打倒有懸賞的海賊或惡徒可領賞金。重複打同一個對手，XP 會遞減。
  - 對海軍或世界政府出手會被懸賞，海軍注意度也會上升。
  - 欺負平民會降低在那座島的聲望；打倒海賊或惡徒會提高聲望。
  - 全隊倒下時，若對手是海賊或山賊，會被搶走三成貝里。
- **海上遭遇**：
  - 航行途中可能遇到海賊船、海軍巡邏或海王類。偉大航路比東海危險，無風帶最容易遇到巨型海王類。
  - 遇到時全隊在船上同步戰鬥。也可以選「甩開對手」，由航海士判定能否擺脫。
  - 打贏、甩開或戰敗後，船都會繼續駛向目的地。
- **XP 與成長**：下一級需要 `100 × 目前等級` XP，每升一級 HP 上限 +2、每兩級 STA 上限 +1，升級時當前 HP／STA 會跟著提高。到等級 4、8、12…… 各得 1 點自由屬性點，在狀態欄按「＋1」分配；提高體魄或意志時，當前 HP／STA 會一起增加。XP 來自委託、戰鬥勝利、交涉成功、成功判定、包紮和首次登上新島；重複的低風險行動收益會依序遞減（100%→50%→25%→0）。
- **不包含**：沒有食物、飲水或飢渴的生存系統；也沒有領地經營。

## 多人與 GitHub Pages

1. 將專案放上 GitHub 儲存庫，在 **Settings → Pages → Source** 選 **GitHub Actions**，再從 **Actions → Publish player web → Run workflow** 發布。工作流程只上傳 `dist/`。
2. 房主保持本機服務和房間頁面開啟，在「遠端邀請與房間設定」等到顯示「遠端邀請就緒」，填入已發布的玩家網站網址並複製邀請連結。玩家也可以在發布後的頁面手動輸入房號。
3. 遠端玩家的瀏覽器透過 PeerJS／WebRTC DataChannel 連到房主的瀏覽器。世界狀態、AI 憑證和 SQLite 都留在房主電腦。同一個瀏覽器可用原本的邀請連結重連；重連憑證存在該瀏覽器的網站儲存空間。

預設使用 PeerJS 的公開訊號服務。要用自架的 PeerServer，可以在建置環境設定 `VITE_SIGNAL_URL`，或在房主本機頁面加上 `?signal=`。如果 NAT 或防火牆擋住直連，可以在「網路中繼（TURN）」填入中繼服務提供的 URL 和短效帳密。跨網路直連不保證一定成功，正式跨網路測試需要實際可用的訊號服務、中繼和兩條不同的網路。

## 存檔、備份與還原

- 服務預設監聽 `127.0.0.1:4173`，SQLite 存在 `data/worlds.sqlite`。可以用 `TIDE_PORT` 和 `TIDE_DB` 改連接埠與存檔路徑。
- 正式結果、世界狀態與待辦都在同一筆交易中提交，事件以唯一 ID 防止重複送出。舊版存檔載入時會自動補上新欄位，例如武器鋪庫存、村長的記憶、屬性點。
- 房主可以按「匯出 SQLite 備份」；本機也會在存檔目錄的 `backups/` 留一份。還原方式：停止服務，把備份檔設為新的 `TIDE_DB` 後重新啟動。之後一樣要先通過 AI 測試，才能開啟原房間。

## 驗收指令

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd test
npm.cmd run test:e2e
```

E2E 需要 Chromium。可以執行 `npx.cmd playwright install chromium`，或把 `TIDE_CHROMIUM` 設成本機 Chrome／Edge 執行檔的完整路徑，例如 `C:\Program Files\Google\Chrome\Application\chrome.exe`。測試會啟動獨立的暫時 SQLite、房主服務、訊號服務和 OpenAI 相容的測試端點（`tests/fixtures.ts`）。正式啟動時只使用真實的 HTTP Provider，沒有任何跳過 AI 的模式。
