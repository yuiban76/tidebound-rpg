# 海賊王 AI RPG：風車村起航

以《海賊王》東海為舞台的 1～4 人繁中純文字 AI RPG 同人作品。故事從魯夫剛乘小船離開黎明島風車村的那天早上開始。玩家角色原本就是朋友，但還沒有海賊團、船長或共同的船。玩家用自然語言行動，房主電腦上的規則引擎負責決定擲骰、時間、金錢、物品與任務結果；AI 只負責理解意圖、旁白和 NPC 台詞。

## 在房主電腦啟動

需安裝 Node.js 24.14 或更新的 24.x 版本。Windows PowerShell 若限制 `npm.ps1`，請改用下列 `npm.cmd`；macOS／Linux 使用 `npm`。

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

1. 先啟動能回傳文字的模型服務，再開啟 [房主介面](http://127.0.0.1:4173)。
2. 首頁的「AI 連線設定」要填 OpenAI 相容 API 的 Base URL、Model ID，以及需要時的 API Key。Base URL 通常以 `/v1` 結尾，例如 Ollama 的 `http://127.0.0.1:11434/v1`、LM Studio 的 `http://127.0.0.1:1234/v1`。
3. 按「**測試連線並生成回覆**」。服務會實際請模型生成一句短回覆，回覆必須是非空白文字才算通過；只是連得上 `/models` 不算。**在測試通過之前，「建立房間」和「開啟存檔」都會停用。** 失敗時會顯示原因分類：連線被拒、找不到端點、認證失敗、模型不存在、逾時、空白輸出、格式不符或推論中斷。
4. 通過後建立房間。每位玩家填寫角色卡、確認原本就是朋友的共同背景並準備。目前在房內的 1～4 人都準備好後，房主即可按「開始遊戲」；按下時服務會再實際生成一次回覆確認 AI 仍可用。
5. 遊戲中 API 失聯時，需要 AI 的正式行動與世界推進都會暫停，已提交的結果和待處理行動會保留。房主重新測試通過後，待處理行動會接著執行。服務閒置五分鐘以上、期間沒有任何成功的生成時，會自動重測一次。
6. API Key 只保存在房主服務的執行記憶體中，服務重啟後需重新輸入。Key 不會送到前端、遠端玩家、WebRTC 封包或事件紀錄。

修改前端時，可在另一個終端執行 `npm.cmd run dev`。Vite 開發伺服器會把本機指令轉送到 `127.0.0.1:4173`。

### 故事線：從東海到頂上戰爭

有船之後可以投票選航線出海。全程共 23 座島：

**東海**（自由航行）
- 黎明島 → 謝爾茲鎮 → 橘子鎮 → 西羅布村 → 海上餐廳巴拉蒂 → 可可亞西村 → 羅格鎮
- 另有原創小島潮燈島與霧灣島。

**偉大航路**（要帶記錄指針，依航線順序前進）
- 羅格鎮 →（翻越顛倒山）→ 雙子岬 → 威士忌山峰 → 小花園 → 磁鼓島 → 阿拉巴斯坦 → 加亞島
- 加亞島之後：
  - 抓到南方鳥的話，可以乘衝天海流上空島，再到七水之都。
  - 也可以直接走遠路到七水之都。
- 七水之都 ↔ 司法島
- 七水之都 → 恐怖三桅帆船 → 夏波帝諸島
- 夏波帝諸島 ↔ 馬林福特
- 夏波帝諸島 ↔ 亞馬遜百合（穿越無風帶）
- 亞馬遜百合 → 推進城：要先取得女帝的協助。
- 推進城 → 馬林福特

**島上內容**
- 每座島有 3 個地點、當地的原作人物，以及 1 個委託。
- 例子：替莉卡把飯糰送給索隆、揭穿阿拉巴斯坦的舞粉真相、在正義之門前救出羅賓、推進城大脫獄、頂上戰爭。
- 偉大航路的單趟航行要花一到四個遊戲日。

**你們不是魯夫**
- 玩家角色是魯夫的同時代人，不必照著主線跑。想當海賊、賞金獵人、商人或醫生都可以，要去哪座島、接不接委託都由你們決定。
- 魯夫也活在這個世界裡，按原作航路自己移動，例如第 2 天在謝爾茲鎮、第 3 天在橘子鎮、第 25 天在阿拉巴斯坦。他到某座島時，如果你們剛好也在那座島上，世界公告會出現【目擊】，你們就能找他聊天。
- 他說的話會隨旅程改變，例如身邊多了哪些夥伴、正要去哪裡。
- 如果你們先改變了局勢，他的行程也會跟著改變。例如先救出艾斯，他就不會去闖推進城。

**時間線**
- 原作事件排在遊戲日曆上，第 1 天早上 8 點是魯夫離開風車村的那一刻。例子：
  - 第 2 天：謝爾茲鎮的蒙卡上校倒下。
  - 第 25 天：阿拉巴斯坦的雨。
  - 第 48 天：司法島。
  - 第 52 天：艾斯被捕。
  - 第 72 天：頂上戰爭。
- 事件到了時間就會發生：NPC 會離開或移動，說的話也會改變。每件事有四個階段：
  - 預兆（約 36 小時前）：【傳聞】，例如酒館裡的閒談。
  - 警告（約 6 小時前）：【警告】，例如「今晚恐怕有海賊登陸」。
  - 發生：隊伍在那座島時是【目擊】；不在時，消息要等報紙。
  - 後續（約 12 小時後）：【後續】，只有還在那座島的隊伍會看到。
  傳聞與警告只有人在那座島上才聽得到；晚到的隊伍上島時也會補聽到還沒發生的傳聞。
- **報紙**：每天 06:00 出刊。消息依海上距離延後，同島即時、鄰近約一天半、最遠三天。玩家打倒的頭目、招募的夥伴也會登上之後的報紙。
- **現場事件**：隊伍在場、而且對手也在時，事件會先暫停進入對峙（【現場】），給你們幾小時介入。打倒對手，事件就會改寫；放著不管，時間到了照原作發生。目前有克洛（西羅布村）、惡龍、艾涅爾、路基、摩利亞、克洛克達爾。
- **旗標**：完成委託、打倒頭目、招募夥伴、持有物品都是旗標（`packages/world/flags.ts`），事件的結果依旗標比對，可以改寫、提前或延後。例如先完成可可亞西村的委託，惡龍樂園會提前 8 小時倒塌；推進城的事件完成後，處刑會延後 3 天。
- **路飛跟著你們走**：你們先招募的原作夥伴，路飛就招不到，他的隊伍會缺人；你們先打倒的頭目，他會改道。
- **共用時鐘**：睡覺和等待都要全隊在線並在同一地點；睡到一半遇到警告或現場事件會被叫醒，只回復睡過的那部分。
- 介面的「日曆與消息」面板顯示現在日期、下一期報紙、現場事件、傳聞與警告和最新報紙。
- 事件的預兆、警告、後續與現場事件資料在 `packages/world/phases.ts`，可以直接增修。
- 原作後續劇情不是腳本。只要在事件發生前完成對應的委託，結果就會改寫。例如：
  - 先揭穿舞粉真相，阿拉巴斯坦的內戰就不會爆發。
  - 在第 70 天艾斯被押走前，先從推進城救出他，頂上戰爭就不會照原作發生。
- 已經被時間線了結的委託會標示為「已落幕」。

**強度門檻**
- 關鍵委託有建議等級和較高的判定難度，例如阿拉巴斯坦 3 級、推進城 7 級、頂上戰爭 9 級；單靠幸運的 D20 無法跨越實力差距。
- 偉大航路的委託和首次登島會給更多 XP，所以只要一路冒險，就能在故事進程中成長到足夠的等級。

在任何一座島上說「去港口」「去碼頭」「去大街」「去處刑台」，都會解讀為目前所在島嶼的那個地點。

### 常用說法

- 「我能去哪裡？」「附近能做什麼？」列出附近地點和提示，不需要等 AI。
- 「去派對酒吧，找瑪琪諾聊天」會先移動再交談；交談中可以直接追問，例如「小艇上是誰？」。
- 「接受潮汐簿委託」「交還潮汐簿」「成立海賊團」「買船」「準備出航」「出海」「出海前往阿拉巴斯坦」「買記錄指針」。
- 「等待 8 小時」「等 3 天」：原地等待，最多 10 天；每滿 8 小時會像睡眠一樣恢復。多人時全隊都要在線並在同一地點才能等待，不會有人單獨把世界時間快轉。
- **戰鬥**：「攻擊村長」「強力攻擊 海賊船員甲」「連續攻擊」「用「風車斬」攻擊 岬恩」「防守」「撤退」「和蘇芮交涉」「使用繃帶給隊友名字」「裝填」。戰鬥面板也有按鈕可以直接帶入指令。
- **轉交與換武器**：「給隊友名字 300 貝里」「把繃帶交給隊友名字」「改用普通長槍」「收起武器」。轉交對象必須是同一地點的隊友。潮汐簿交給隊友後，改由接手的人交付委託。
- 世界公告上方的地圖會顯示步行地點和隊友位置，點地點會把移動指令帶進行動欄。

## 規則重點

- **人數與決議**：N 是已入隊並持有角色的真人玩家數（1～4）。一般決議門檻為 `floor(N/2)+1`；成立海賊團、出售主船等重大決議需要 N/N 全員同意；跨島出航需要全員到船邊並準備。斷線的玩家仍算在 N 裡。
- **開局後加入**：故事開始後，人數未滿 4 人時仍可用邀請連結加入。新玩家先完成角色卡、確認背景並準備，隨後在隊伍主船停泊的港口（還沒有船時則是風車村港口）與大家會合，世界公告會寫出這件事。加入前不算進 N，也不能行動或投票；入隊後，進行中的重大決議要連新人一起同意。
- **武器與道具店**：風車村廣場的鐵匠鋪、哥亞城下町武器鋪、羅格鎮一本松武器店都能「強化武器」，只強化手上那一種（刀、槍、火槍、徒手各自計算）。共三階：1 階 400 貝里（等級 2）、2 階 1200 貝里（等級 5）、3 階 3000 貝里（等級 8），每階命中 +1、傷害 +2。城下町另賣普通火槍（900 貝里），鐵匠鋪賣傷藥（120 貝里，「喝傷藥」回復 8＋等級 點 HP 與 5 點 STA，戰鬥中不能喝）。
- **D20 與戰鬥**：固定 DEF＝12＋AGI＋閃避。自然 20 有效命中時加擲一次武器骰。HP 歸零是倒下而不是死亡。戰鬥採同步回合：同地的隊友都會參戰，全員鎖定行動後同時結算，離線的參戰者不會被代為操作。
- **對手**：
  - 任何 NPC 都能攻擊。強度依原作分成平民、雜兵、戰士、軍官、精英、七武海／大將級、傳說級，等級差距大時幾乎打不中。
  - **團戰**：對船長或任何團員出手，此刻和他在一起的整團人會一起迎戰，在大本營還會有雜兵助陣。例如：
    - 打魯夫時，當下已經上船的草帽一夥會全員出戰，成員依原作時間加入，第 59 天在夏波帝被打散後就不在一起。
    - 其他團體：巴其、黑貓、克利克、惡龍、達丹一家、瓦波爾、貝拉米、巴洛克工作社、CP9、摩利亞、基德、白鬍子。
    - 你們先招募走的人會站在你們這邊一起打；昏迷中的成員不參戰。
    - 名冊在 `packages/world/crews.ts`，可以直接增修。
  - 自然系的身體會讓普通攻擊穿過，但有解法（見「自然系對策」）；艾斯、黑鬍子與三位大將在霸氣加入前碰不到。
  - 被打倒的 NPC 會昏倒 8 小時，期間無法交談；他們會記得是誰打倒了自己。
  - 打倒原作頭目會立刻改變世界，原作事件也會改寫成「早已被一群旅人打倒」。例如惡龍、克洛、貝拉米、摩利亞、路基。
- **招式與體力**：
  - 普通攻擊 0 STA；強力攻擊 2 STA（傷害＋2）；基礎特殊招式 3 STA（命中＋1、傷害＋3）；進階招式 5 STA（命中＋2、傷害＋5）；連續攻擊 7 STA（連打兩下，命中各－2）。
  - 可以在狀態欄自創最多 6 個招式，只決定名稱與等級，華麗的名字不會讓它更強。
- **戰鬥中的行動**：防守（DEF＋2）、撤退（退到相鄰地點）、交涉（勸對手收手，精英以上不為所動）、使用繃帶（治療自己或同地隊友）、裝填火槍。
- **戰利品、賞金與聲望**：
  - 打倒對手可得貝里和 XP；打倒有懸賞的海賊或惡徒可領賞金。重複打同一個對手，XP 會遞減。
  - 對海軍或世界政府出手會被懸賞，海軍注意度也會上升。
  - 欺負平民會降低在那座島的聲望；打倒海賊或惡徒會提高聲望。
  - 全隊倒下時，若對手是海賊或山賊，會被搶走三成貝里。
- **海上遭遇**：
  - 航行途中可能遇到海賊船、海軍巡邏或海王類。偉大航路比東海危險，無風帶最容易遇到巨型海王類。
  - 遇到時全隊在船上同步戰鬥。也可以選「甩開對手」，由航海士判定能否擺脫。
  - 打贏、甩開或戰敗後，船都會繼續駛向目的地。
- **XP 與成長**：下一級需要 `100 × 目前等級` XP，每升一級 HP 上限 +2、每兩級 STA 上限 +1，升級時當前 HP／STA 會跟著提高。到等級 4、8、12…… 各得 1 點自由屬性點，在狀態欄按「＋1」分配；提高體魄或意志時，當前 HP／STA 會一起增加。XP 來自委託、戰鬥勝利、交涉成功、成功判定、包紮和首次登上新島；重複的低風險行動收益會依序遞減（100%→50%→25%→0）。
- **不包含**：沒有食物、飲水或飢渴的生存系統；也沒有領地經營。

## 恢復 HP／STA

- **休息**（輸入「休息」「休息一下」）：30 分鐘，回復約 1/4 STA 與 1/10 HP。
- **睡覺**（輸入「睡覺」「睡一覺」「過夜」）：8 小時，STA 全滿、HP 回復 1/4；山徑不能休息。
- **等待**（輸入「等待 8 小時」）：每滿 8 小時視為一夜，全隊 STA 全滿、HP 回復 1/4，夥伴也會恢復。
- **吃東西**：在酒館吃烤麵包（15 貝里，HP+2、STA+4）或燉肉飯（35 貝里，HP+5、STA+8）。
- **繃帶**：港口補給鋪購買，替自己、同地隊友或夥伴包紮。
- 夥伴系統裡的喬巴會讓睡覺與等待的回復更多。
- HP 或 STA 偏低時，「我能去哪裡？」會自動列出可用的回復方式；狀態側欄也有「恢復」面板與一鍵填入指令的按鈕。

## NPC 夥伴系統

成立船團後，可以邀請認識的 NPC 加入，他們會真正跟著你移動、搭船、參戰。夥伴狀態由規則核心管理，AI 只負責旁白，不能自行決定誰加入或離隊。

- **邀請／離隊**：輸入「邀請騙人布加入」「叫香吉士加入我的海賊團」或「請騙人布離隊」。這些句子不需要 AI 也能辨識；AI 分類器同樣支援 `recruit`／`dismiss` 意圖。
- **可招募名單**：除了魯夫、艾斯、白鬍子、戰國、雷利、拉布和岬恩（劇情核心或不能離開，邀請時會說明原因），其他 NPC 都能邀請，包括一般居民和反派。騙人布、卓洛、香吉士、薇薇、喬巴、羅賓、佛朗基、布魯克和提燈人有手寫的個性與條件（例如香吉士需先到巴拉蒂、卓洛需隊伍等級 3）；其他人依角色與強度自動產生：居民的難度依個人強度與身上的責任（村長、老闆、醫生等較難）；反派難度較高，而且隊伍等級要夠（約為對方強度加 2），先打倒過他們則有 +4 服氣加成。數值與條件定義在 `packages/world/companions.ts`，可直接調整。招募原作頭目會改寫對應的原作事件（例如克洛、惡龍、艾涅爾、路基、摩利亞、克洛克達爾被收服後不會再發動原本的事件）。
- **判定**：D20 + WIL + 說服，與對方有交情（信任任務）時 +4；自然 20 必成功、自然 1 必失敗。失敗後 120 分鐘內不能再邀請同一人。
- **上限**：整個船團（真人玩家加夥伴）最多 10 人，所以夥伴名額是 10 減去玩家人數；需要先成立船團。
- **跟隨**：夥伴所在地永遠等於隊長所在地；出航抵達新島時會一起上岸。時間線事件不會移動或改寫夥伴。
- **戰鬥**：夥伴每回合攻擊血量最低的敵人，也可能成為敵人的攻擊目標；HP 歸零會倒下休息 8 小時後自動恢復。夥伴不能被你攻擊。
- **恢復**：休息、等候過夜與包紮都會治療夥伴，隊伍有醫生型夥伴（喬巴）時效果更好。
- **介面**：狀態側欄的「夥伴」面板顯示 HP、位置，並提供交談／離隊／邀請按鈕（按鈕只會把指令填入輸入框）。
- **人氣角色與行程**：除了最初的 54 位，另外加入 36 位人氣角色（娜美、巴其、克利克、密佛格、羅、基德、甚平、黃猿、馬可……），資料在 `packages/world/cast.ts`。每個人的 Day 1 位置與之後的行程都依原作時間線推算（例如娜美第 3 天在橘子鎮、第 7 天在惡龍樂園、第 8 天上船；黃猿第 58 天到夏波帝；頂上戰爭當天各路人馬聚到馬林福特）。被你招募的人不會被行程帶走；招募巴其、克利克、娜美、瓦波爾會改寫對應的原作事件。龍、香克斯、卡普、三大將和大熊不能招募。
- 測試：`node --experimental-strip-types --test tests/companions.test.ts tests/cast.test.ts`

## 戰鬥數值與等級

- 升級會讓角色真的變強：HP 上限每級 +4；命中每 4 級 +3（等級 × 0.75，無條件捨去）；傷害每 2 級 +1；防禦每 3 級 +1。一級時全部是 0，和舊規則相同。繃帶回復量每 2 級 +1。
- NPC 夥伴用同樣的曲線成長（命中、傷害、防禦、HP 都跟著隊伍最高等級走）。
- 對手強度分七階（平民、雜兵、戰士、軍官、精英、七武海／大將級、傳說級）。標準劍士（力量 4、敏捷 3、體魄 3）用強力攻擊打單一對手的勝率（Monte Carlo 模擬，`tests/balance.test.ts` 會鎖住這些範圍）：
  - 單人：一級打不贏第 3 階（<10%），六級約 80%；十級打第 4 階約 60%。
  - 兩人：二級打不贏第 4 階，五級約 60%；十二級打第 5 階約 60%。
  - 四人：四級還打不贏第 5 階，八級約 95%；十二級打第 6 階約 55%。
- 數值集中在 `packages/rules/engine.ts` 的 `maxHP`、`levelHit`、`levelDamage`、`levelDefense`，對手階級表在 `packages/world/foes.ts` 的 `tierStats`，夥伴在 `packages/world/companions.ts` 的 `tierFight`。
- **惡魔果實**（`packages/world/fruits.ts`、`packages/rules/fruits.ts`）：
  - 35 位 NPC 各帶一顆果實（魯夫的橡膠果實不能搶，故事要靠它）。打倒（不是勸降）這些 NPC 後，最後一擊的玩家會看到果實掉出來，輸入「吸收果實」吃下，或「放走果實」。
  - 吃下：每顆果實有五招（原作招式，名稱為本作譯名），依等級 1／3／6／9／12 學會：前兩招 3 STA、第三四招 5 STA、第五招 7 STA（連續兩擊），升級時自動學會；原創果實可以少於五招，每一擊傷害提高（果實階級＋等級）。自然系：被普通對手打中只受一半傷害，且打得到其他自然系（包含艾斯等沒有弱點的人）；動物系：HP 上限 +10。代價是不能游泳，海上戰鬥防禦 −2。一個人只能吃一顆。對方失去能力（斯摩格等不再是自然系）。
  - 放走：果實流到外面，報紙會登傳聞，三天後出現在夏波帝人口拍賣所，任何人都能標下（階級 1／2／3 分別是 200 萬／500 萬／1200 萬貝里）。沒人理會的果實兩天後自動放走。
  - 想買：到人口拍賣所輸入「買煙煙果實」。右側「惡魔果實」面板有按鈕。
  - 測試：`tests/fruits.test.ts`。
- **自然系對策**（霸氣加入前）：被打不到時，戰鬥訊息會提示對策。
  - 克洛克達爾怕水：到那諾哈娜雜貨攤買「水壺」（30 貝里），戰鬥中輸入「用水壺潑克洛克達爾」，他現形 3 回合，全隊（含夥伴）都打得到。
  - 艾涅爾怕衝擊貝：到天使海灘貝殼攤買「衝擊貝」（300 貝里），輸入「用衝擊貝攻擊艾涅爾」，現形 2 回合。
  - 斯摩格、克洛克達爾、艾涅爾都怕海樓石：到羅格鎮一本松武器店買「海樓石十手」（3000 貝里，只有 1 把），帶在身上，持有者自己的攻擊就打得到。
  - 艾斯、黑鬍子、赤犬、青雉、黃猿沒有弱點，現在打不到，是留給之後霸氣的門檻。
  - 資料在 `packages/world/foes.ts`（`weak` 欄位）與 `packages/world/village.ts`（商品），測試在 `tests/combat.test.ts`。

## 多人與 GitHub Pages

1. 將專案放上 GitHub 儲存庫，在 **Settings → Pages → Source** 選 **GitHub Actions**，再從 **Actions → Publish player web → Run workflow** 發布。工作流程只上傳 `dist/`。
2. 房主保持本機服務和房間頁面開啟，在「遠端邀請與房間設定」等到顯示「遠端邀請就緒」，填入已發布的玩家網站網址並複製邀請連結。玩家也可以在發布後的頁面手動輸入房號。
3. 遠端玩家的瀏覽器透過 PeerJS／WebRTC DataChannel 連到房主的瀏覽器。世界狀態、AI 憑證和 SQLite 都留在房主電腦。同一個瀏覽器可用原本的邀請連結重連；重連憑證存在該瀏覽器的網站儲存空間。

預設使用 PeerJS 的公開訊號服務。要用自架的 PeerServer，可以在建置環境設定 `VITE_SIGNAL_URL`，或在房主本機頁面加上 `?signal=`。如果 NAT 或防火牆擋住直連，可以在「網路中繼（TURN）」填入中繼服務提供的 URL 和短效帳密。跨網路直連不保證一定成功，正式跨網路測試需要實際可用的訊號服務、中繼和兩條不同的網路。

## 存檔、備份與還原

- 服務預設監聽 `127.0.0.1:4173`，SQLite 存在 `data/worlds.sqlite`。可以用 `TIDE_PORT` 和 `TIDE_DB` 改連接埠與存檔路徑。
- 正式結果、世界狀態與待辦都在同一筆交易中提交，事件以唯一 ID 防止重複送出。舊版存檔載入時會自動補上新欄位，例如武器鋪庫存、村長的記憶、屬性點。
- 房主可以按「匯出 SQLite 備份」；本機也會在存檔目錄的 `backups/` 留一份。還原方式：停止服務，把備份檔設為新的 `TIDE_DB` 後重新啟動。之後一樣要先通過 AI 測試，才能開啟原房間。

## 驗收指令

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd test
npm.cmd run test:e2e
```

E2E 需要 Chromium。可以執行 `npx.cmd playwright install chromium`，或把 `TIDE_CHROMIUM` 設成本機 Chrome／Edge 執行檔的完整路徑，例如 `C:\Program Files\Google\Chrome\Application\chrome.exe`。測試會啟動獨立的暫時 SQLite、房主服務、訊號服務和 OpenAI 相容的測試端點（`tests/fixtures.ts`）。正式啟動時只使用真實的 HTTP Provider，沒有任何跳過 AI 的模式。
